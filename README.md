# sIDE

**A GUI for your coding agents.** Works with your own subscriptions to Claude Code, Codex, Cursor, Grok Build, OpenCode, Antigravity, Pi, omp, fx, Hermes Agent and Devin.

This repository hosts sIDE's releases. The source is private.

## Download

Get `sIDE_<version>_aarch64.dmg` from the [latest release](https://github.com/sidoexe/side-releases/releases/latest) (Apple Silicon Macs), open it and drag sIDE to Applications. The app is not signed with an Apple Developer ID, so confirm its first launch with right-click → **Open**. sIDE then updates itself from this page.

Each release also carries the host packages that remote machines install, and the unsigned iOS IPA.
